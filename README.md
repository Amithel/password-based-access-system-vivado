# password-based-access-system-vivado

A digital logic access control system designed and simulated in Xilinx Vivado using Verilog HDL.

## Features
- **Password Verification:** Compares user key inputs against a stored key.
- **State Logic:** Implements finite state machine (FSM) control for locked/unlocked states.
- **Simulation:** Includes testbench (`tb_digital_lock_simple.v`) for functional waveform verification.

## Project Structure
- `project_3.srcs/` - Contains Verilog source code, testbenches, and block design.
- `project_3.xpr` - Main Vivado project file.

## Tools Used
- Xilinx Vivado
- Verilog HDL
